## Radare (iaito)

Build [radare](https://github.com/radareorg/iaito) from source

```sh    
git clone https://github.com/radareorg/iaito.git
apt-get install qt5-default
cd /usr/local/ ; ln -s /usr/local/include/libr
r2pm -ci r2ghidra r2frida r2dec
```
